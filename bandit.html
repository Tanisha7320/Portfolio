Linux / Security Fundamentals

OverTheWire Bandit

I worked through OverTheWire’s Bandit wargame to Level 28, solving command-line challenges in a deliberately controlled environment.

Linux Bash SSH Networking

What I practiced

The challenges helped me get more comfortable exploring unfamiliar filesystems and combining small shell tools to locate and inspect data. I practiced file and directory permissions, ownership, text searches, pipelines, and working with encoded or compressed files.

Later levels introduced SSH keys, network clients and services, scheduled jobs, and programs with elevated permissions. Working through them meant reading command output carefully, forming a hypothesis, and adjusting the approach when the first command did not work.
