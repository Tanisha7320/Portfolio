02 / Reinforcement Learning

Prospect Theory in Q-Learning

What changes when a Q-learning agent treats a reward below its expectations as a loss?

Python Gymnasium Behavioral Economics

Experiment

I trained two tabular Q-learning agents on Gymnasium’s slippery FrozenLake, where the agent’s intended move can lead to an unexpected tile. Both agents use the same update rule. One receives the environment’s original rewards, while the other learns from transformed rewards.

Modeling loss aversion

I built a reward wrapper that evaluates each reward relative to a reference point of 0.01. A zero reward therefore becomes a small penalty. The wrapper uses a power of 0.88 for both gains and losses, and scales losses by 2.25 to give them more weight than equivalent gains.

Reading the training curves

The script plots a 50-episode moving average for each agent. The curves use different reward scales, so their heights show how each training signal evolves. Comparing navigation performance would require evaluating both agents with a shared metric such as goal-reaching rate.
